# local/ 本机数据目录

本目录存放 **Scroll Reverser skill 的本机私有数据**：用户这台 Mac 上的应然配置快照（`config.md`，含惯用开关组合、实际安装路径、一键恢复命令块）。

按「Skill 内容纯净性」规矩（核心可开源 + 私人信息用户级存放），`config.md` 属于本机环境细节，**不进开源镜像**——clone 者拿到的 skill 只含通用方法（SKILL.md 与 references/），本机数据各自维护在本目录。

新机器上使用本 skill 时，按 SKILL.md 通用流程操作即可；如需本机快照，参照 `config.md` 的格式在本目录自建一份。
