# Windows SSH 远程操作规范（ssh win-ai）

## 背景

Mac 本机已配置通过 SSH 管理同一局域网内的一台 Windows 机器，`~/.ssh/config` 里定义了两个别名（HostName、User、IdentityFile 的真实值见该文件），都用专用密钥免密登录：

- `win-ai`：普通权限账户，默认走这条；
- `win-ai-admin`：管理员账户，仅经用户同意后用于需要管理员权限的操作。

## 规则

1. **默认以普通权限执行**：对这台 Windows 机器的操作，默认通过别名 `ssh win-ai` 执行（公钥免密、普通权限账户）。脚本、指令、文档里只写别名，不写真实 IP、用户名、密码。
2. **需要管理员权限时先征求用户同意**：遇到需要管理员权限的操作（如安装 / 卸载软件、修改系统服务、改防火墙或系统设置等），AI 先向用户说明要做什么、为什么需要管理员权限，**征得用户同意后**再以管理员身份（`ssh win-ai-admin`）执行本次操作；**默认不主动使用管理员权限**。拿不准某操作是否需要管理员权限时，按需要询问用户，宁可多问一次，不擅自提权。
3. 管理员通道 `win-ai-admin` 与普通通道一样是公钥免密，无需也不应使用密码文件。
4. 需要记录连接方式时，用别名加占位符（例如「`ssh win-ai`、`ssh win-ai-admin`，真实连接信息见本机 `~/.ssh/config`」），不把真实 IP、用户名写进任何会被 git 跟踪的文件。

## 边界

- 本规则只管「用什么身份、怎么连」；具体命令的操作边界由各项目 / 用户另行约定。
- 若本机没有 `win-ai` 别名（换机器、重装系统后未重新配置），本规则不适用，先由用户重新配置连接。
